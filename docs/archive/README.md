# docs/archive

Retired documents, kept for history. **Nothing in this folder is authoritative.**

If you are looking for what to build next, that is `ROADMAP.md` in the repo root,
and only that. Everything here was folded into it on 18 September 2026 — every
still-open item was carried across before the move.
